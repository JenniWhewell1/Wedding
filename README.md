# Wedding Website Template

A simple, elegant, responsive wedding website starter.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive styling
- `wedding.json` — editable wedding data/content
- `README.md` — setup notes

## Quick start
1. Open `index.html` in a browser.
2. Replace the couple's names, date, venues, schedule and RSVP deadline.
3. Update the hero image URL in `styles.css`, or replace it with a local image.
4. Connect the RSVP form to your preferred form/backend service before publishing.

## Important
The JSON file is a content template; the supplied HTML is intentionally static so it works immediately without a build system. If you want, the next version can load `wedding.json` dynamically with JavaScript and add a gallery, countdown, map, travel/accommodation section and a working RSVP backend.
